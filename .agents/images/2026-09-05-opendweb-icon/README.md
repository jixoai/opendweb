# opendweb icon

Transparent Web/App icon assets. The four-color organic forms borrow openiweb's compact, hand-drawn visual language while the dark connector lines and shared center communicate private peer-to-peer links.

- `opendweb-icon.png` is the 1254x1254 RGBA image generated directly with `gpt-image-2` using `background=transparent`.
- `opendweb-icon.svg` is a vector redraw matching the final four-lobe topology and connector layout.
- `openai-image-bb9e578b.png` and `1788621134221-0.png` are the original magenta-background candidates; they are retained as source references only.

The PNG uses native alpha from the image provider. Low-alpha stray pixels were removed; it contains no magenta matte and is suitable for compositing on light or dark surfaces.
